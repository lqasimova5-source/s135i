# S135i — Class Website

A responsive class website created for the S135i Computer Engineering group. It brings together the group's identity, student directory, and shared memories in one web experience.

## Features

- Responsive single-page design
- Student directory with portraits and roles
- Memories gallery
- Mobile-friendly layout
- Lazy-loaded images
- Accessibility improvements
- Custom visual identity

##  Built With

- HTML5
- CSS3
- Git & GitHub
- Vercel

##  What I Learned

Through this project, I practiced:

- Responsive web design
- Semantic HTML
- CSS layout and styling
- Accessibility basics
- Managing media assets
- Git and GitHub workflow
- Deploying and updating a live website

##  About the Project

This website was created for my university group and has been continuously improved based on real use and feedback.
